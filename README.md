# Random Quote Generator

A clean, responsive quote generator built with HTML, CSS, and JavaScript for the CodeAlpha internship Task 2.

## Features
- Displays a random quote when the page opens.
- The **New Quote** button selects another quote.
- Displays the quote and author clearly.
- Avoids repeating the same quote twice in a row.
- Responsive layout for desktop and mobile screens.

## Run locally
1. Download or extract the project folder.
2. Open `index.html` in a web browser.
3. Click **New Quote** to display another quote.

## Files
- `index.html` — page structure
- `style.css` — design and responsive styling
- `script.js` — quote data and random selection logic
